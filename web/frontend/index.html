1. 현재 경기 상황

현재 타석의 상황과 투수·타자 좌우 정보를 입력합니다.

데모 투수 기준
현재 화면은 고정 예시 투수 ID를 기준으로 추천합니다. 학습 기간에 해당 투수가 없으면 미등록 투수로 처리합니다. 타자 방향은 LSTM이 구종 후보를 정할 때 사용하는 입력입니다.
직접 선택 모드에서는 추천 후보를 1개 이상 선택합니다. 이전 투구는 따로 입력합니다.
현재 모델 범위
현재 데모는 이전 투구 흐름, 볼카운트, 주자 상황, 투수 손, 타자 방향을 중심으로 추천합니다. 점수 차, 오늘 투구 수, 선발/구원 여부, 구속, 회전수는 아직 직접 반영하지 않았으며 향후 확장 항목입니다.

점수는 학습 구간에서 관측된 투구를 바탕으로 추정한 기대득점 변화입니다. 점수가 낮은 후보부터 추천합니다.
표본 수는 해당 통계에 사용된 투구 건수입니다. 서빙에서 전체 평균을 사용하면 표본 수는 미제공으로 표시합니다.
